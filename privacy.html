Privacy Policy

Last updated: September 2026

What this application is

Mrog (the Corporate Fraud Documentary Pipeline) is a private tool operated by a single person to publish videos to that person's own YouTube channel. It is not offered to the public and has no user accounts.

Google user data it accesses

Through the YouTube Data API and YouTube Analytics API, with the operator's own Google account authorization, the application:

  • uploads videos to the operator's channel and sets their titles, descriptions, tags, thumbnails, and privacy status;
  • reads view and watch-time statistics for videos it uploaded.

It does not read subscriber lists, comments, messages, or any data belonging to other YouTube users, and it does not access any other Google service.

How data is stored and used

The OAuth refresh token and the statistics it reads are stored only on the operator's own computer, in a local configuration file and a local database. They are used solely to operate the channel. No data is sold, shared with third parties, used for advertising, or used to train models.

Third-party services

Video narration and illustrations are generated by third-party AI services from the script text alone. No Google user data is sent to them.

Retention and deletion

Statistics are kept locally for as long as the channel is operated. The operator can revoke the application's access at any time at myaccount.google.com/permissions, after which the stored token is useless and is deleted.

Limited Use disclosure

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions about this policy can be sent to the contact email shown on the channel's About page.
